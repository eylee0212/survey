# 설문 집계기

엑셀에서 머리글 줄까지 선택해 복사한 뒤 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 한 장짜리 페이지입니다.

- `index.html` 하나로 동작합니다. 파일을 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.
- 외부 라이브러리·글꼴·분석 도구를 쓰지 않습니다. 붙여넣은 데이터는 브라우저 밖으로 보내지 않고 어디에도 저장하지 않습니다(콘텐츠 보안 정책으로 외부 연결을 막음).

## 집계 규칙

- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`~`5`면 유효, 비었거나 공백뿐이면 빈 응답, 그 밖의 값은 제외합니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 표시하며, 유효 응답이 없으면 `-`입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다.

자세한 규칙과 요청에 없어 정한 사항은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

```bash
npm test
```

Node 22 이상이 필요하고 설치할 의존성은 없습니다. 시험은 `index.html` 안의 계산 블록(`<script id="survey-core">`)을 꺼내 그대로 실행합니다. Playwright가 설치된 환경에서는 실제 브라우저로 붙여넣기 시험도 함께 돌고, 없으면 그 시험만 건너뜁니다.
