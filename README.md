# 10×10 삼목

10×10 판에서 가로·세로·대각선으로 자기 돌 3개를 먼저 이으면 이기는 게임입니다. `index.html` 한 장으로 동작합니다.

- 바로 하기: https://eylee0212.github.io/survey/
- 상대: 두 사람(한 기기), 또는 컴퓨터(내가 먼저 / 컴퓨터가 먼저)
- 무르기, 새 게임, 키보드 조작(방향키로 칸 이동, Enter·Space로 두기)
- 외부 라이브러리·글꼴·분석 도구 없음. 외부와 통신하거나 저장하지 않습니다.

## 규칙

- 흑이 먼저, 흑·백이 번갈아 빈 칸에 돌을 하나씩 둡니다.
- 한 방향으로 자기 돌이 3개 이상 이어지면 이깁니다.
- 승자 없이 100칸이 다 차면 무승부입니다.

참고: 넓은 판에서 3개 잇기는 먼저 두는 쪽이 반드시 이길 수 있습니다(돌 두 개를 양 끝이 열리게 붙이면 상대가 한쪽만 막을 수 있음). 컴퓨터는 이 수를 알고 있어서, 컴퓨터가 먼저 두면 항상 이깁니다.

자세한 설계는 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

```bash
npm test
```

Node 22 이상이 필요하고 설치할 의존성은 없습니다. 시험은 `index.html` 안의 게임 로직 블록(`<script id="game-core">`)을 꺼내 그대로 실행합니다. Playwright가 설치된 환경에서는 실제 브라우저로 클릭해 두는 시험도 돌고, 없으면 그 시험만 건너뜁니다.
