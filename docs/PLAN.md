# 설문 집계기 계획서

## 목표

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 페이지를 `index.html` 하나로 만든다.

## 지켜야 할 조건

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다. 모든 코드와 스타일은 `index.html` 안에 둔다.
- 붙여넣은 데이터는 브라우저 밖으로 보내지 않고 어디에도 저장하지 않는다.
  - `localStorage`·`sessionStorage`·IndexedDB·쿠키를 쓰지 않는다.
  - 네트워크 요청 코드를 쓰지 않는다. 덧붙여 콘텐츠 보안 정책(CSP)으로 `connect-src`·`img-src`·`font-src`·`form-action` 등을 모두 막아 실수로도 나가지 못하게 한다.
  - 입력 칸은 `spellcheck="false"`·`autocomplete="off"`로 둔다. 브라우저의 확장 맞춤법 검사가 글을 서버로 보내는 일을 막기 위해서다.
  - `<form>` 제출을 쓰지 않는다.
- 저장소 맨 위에 빈 `.nojekyll` 파일을 둔다(GitHub Pages가 Jekyll 처리를 하지 않게).

## 집계 규칙

| 항목 | 규칙 |
|---|---|
| 입력 | 탭으로 나뉜 칸, 줄바꿈(`\r\n`·`\n`·`\r`)으로 나뉜 줄. 첫 줄은 머리글. |
| 첫 열 | 응답번호. 집계하지 않는다. |
| 유효 | 앞뒤 공백을 지운 값이 `1`·`2`·`3`·`4`·`5` 중 하나 |
| 빈 응답 | 비었거나 공백만 있는 칸 |
| 제외 | 그 밖의 모든 값(`0`, `6`, `3.0`, `１`(전각), `3점`, `N/A` 등) |
| 칸이 모자란 줄 | 모자란 칸을 빈 응답으로 센다 |
| 평균 | 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지(`3.00`처럼 0도 표시). 유효가 0이면 `-` |

결과 표의 열: **문항 / 유효 응답 / 평균 / 빈 응답 / 제외**

### 요청에 없어서 정한 세부 사항

- **반올림**: 합과 개수가 정수이므로 정수 연산으로 사사오입한다(`floor((200×합 + 개수) ÷ (2×개수))`를 100으로 나눔). 부동소수점 오차(예: 2.675 → 2.67) 없이 2.675 → 2.68이 된다.
- **끝의 빈 줄**: 엑셀 복사본은 마지막에 줄바꿈이 붙으므로 맨 끝의 완전히 빈 줄은 버린다. 중간의 빈 줄은 규칙대로 "칸이 모자란 줄"로 보고 모든 문항을 빈 응답으로 센다(응답 줄 수에 포함). 화면에 그런 줄이 있었다는 안내를 띄운다.
- **칸이 넘치는 줄**: 머리글보다 칸이 많으면 넘치는 칸은 집계하지 않고, 몇 줄이 그랬는지 안내한다.
- **따옴표 칸**: 엑셀은 탭·줄바꿈·따옴표가 든 칸을 `"…"`로 감싸 복사한다. 칸이 `"`로 시작하면 따옴표 칸으로 읽고 `""`를 `"` 하나로 바꾼다. 그 칸의 값은 보통 제외 처리된다.
- **문항 이름**: 머리글 칸의 앞뒤 공백을 지운 값. 비었으면 `(N열)`로 표시한다.
- **문항이 없는 경우**: 머리글이 한 칸(응답번호)뿐이거나 입력이 비면 표 대신 안내 문구를 보인다.
- 화면에 넣는 값은 모두 `textContent`로 넣어 붙여넣은 내용이 HTML로 해석되지 않게 한다.

## 구조

- `index.html`
  - `<script id="survey-core">`: 화면을 모르는 순수 계산 함수(`parseTable`, `classifyCell`, `formatAverage`, `summarize`). DOM·`window`를 쓰지 않는다. `SurveyCore` 객체 하나로 내보낸다.
  - `<script id="survey-ui">`: 입력 칸을 읽어 `SurveyCore.summarize`를 부르고 표를 그린다. 입력이 바뀔 때마다 다시 집계한다.
- `tests/core.test.js`: Node 내장 시험 도구(`node --test`)로 실행한다. `index.html`에서 `survey-core` 블록을 꺼내 `vm`으로 돌리므로 실제 배포되는 코드를 그대로 시험한다.
- `tests/page.test.js`: `index.html`에 외부 주소(`http`, `//`)를 가리키는 `src`·`href`, 저장소·네트워크 API(`fetch`, `XMLHttpRequest`, `localStorage` 등)가 없는지, CSP가 있는지 확인한다.
- `package.json`: `npm test` → `node --test tests/`. 의존성 없음.
- `.github/workflows/test.yml`: 푸시·PR마다 `npm test` 실행.

## 작업 순서(작업마다 커밋)

1. 계획서 작성 (`docs/PLAN.md`)
2. `.nojekyll` 추가
3. 계산 로직 + 시험 (`index.html`의 core 블록, `tests/core.test.js`, `package.json`)
4. 화면 (`index.html`의 UI 블록과 스타일) + 페이지 점검 시험
5. 자동 시험 워크플로 + README
6. 브라우저로 실제 붙여넣기 확인 후 PR
